Programming Applications Final Project: Hawk-Dove Evolutionary Game

In my Programming Applications course, as my final project, I developed a Python-based simulation of the Hawk-Dove Evolutionary Game. This project explored evolutionary stable strategies (ESS), computational modeling, and population dynamics through mathematical simulation. Using numerical methods and data visualization, I analyzed how competing strategies evolve over time under different conditions.

Skills Demonstrated: Python programming, debugging, object-oriented design, algorithm development, and computational problem solving.
